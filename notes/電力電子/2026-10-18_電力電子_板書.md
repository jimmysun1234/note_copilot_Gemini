## 📌 3 分鐘核心摘要
- **RL 負載半波整流與續流二極體**：當負載電感趨近於無限大時，負載電流可視為恆流源；輸出平均電壓為 $V_X = V_s / \pi$。
- **全波整流與 RL 負載**：全波橋式電路在正負半週均有路徑導通，平均輸出電壓加倍為 $V_X = 2V_s / \pi$。
- **換相重疊現象（Commutation Overlap）**：考量電源端漏感 $L_c$ 時，主二極體與續流二極體在換相區間內會同時導通，導致負載端瞬間短路使輸出電壓為零。
- **漏感對輸出特性的壓降效應**：漏感的存在會使平均輸出電壓隨負載電流線性下降，電路可等效為理想整流電壓源串聯一個與頻率及漏感成正比的等效內阻。

## 📖 結構化重點筆記
## 一、含大電感負載之整流電路基本分析

### 1. 含續流二極體之半波整流電路（RL-load）
- **電路結構**：交流電源 $v_s = V_s \sin(\omega t)$ 經主二極體 $D_1$ 接至 $R-L$ 負載，並在負載側並聯續流二極體 $D_2$。
- **大電感假設**：當 $L \to \infty$ 時，電感電流無法突變且紋波趨近於零，負載可等效為理想恆流源 $I_L$。
- **工作模式**：
  - **模式 I（$v_s > 0$）**：$D_1$ 導通、$D_2$ 截止，輸出電壓 $v_X = v_s$。
  - **模式 II（$v_s < 0$）**：$D_1$ 截止、$D_2$ 導通續流，輸出電壓 $v_X = 0$。
- **輸出電壓與電流平均值**：
  根據電感穩態伏秒平衡，電感跨壓平均值 $\langle v_L \rangle = 0$，故輸出平均電壓等於電阻平均電壓：

$$\langle v_X \rangle = \langle v_R \rangle = V_X$$

$$V_X = \frac{1}{T} \int_{0}^{\frac{T}{2}} V_s \sin(\omega t) dt = \frac{V_s}{\pi}$$
  平均負載電流為：

$$

I_R = \frac{V_X}{R} = \frac{V_s}{\pi R}$$

### 2. 全波整流電路（Full-wave Rectifier with RL-load）
- 負載同樣接大電感與電阻（$L \to \infty$）。
- 在全週期內正負半週均有對應二極體導通供電：
  - 正半週 $v_s > 0$：$v_X = v_s$
  - 負半週 $v_s < 0$：$v_X = -v_s$
- 平均輸出電壓為半波整流的兩倍：

$$

V_X = \langle v_X \rangle = \frac{2 V_s}{\pi}$$

## 二、考量電源端漏感（Leakage Inductance $L_c$）之換相分析

在實際電路中，交流電源側具有漏感 $L_c$，電感電流不能瞬間轉移，導致二極體換流無法瞬間完成，產生換相重疊（Overlap）。

### 1. 換相過程狀態劃分
依據節點 KCL 定律，負載電流滿足：

$$

i_L = i_{D1} + i_{D2} = I_L$$
二極體工作狀態可分為不同區間：

- **換相區間 Mode I（$t = 0 \sim t_a$）**：
  - $D_1$ 與 $D_2$ 同時導通（ON），負載端被 $D_2$ 短路，故 $v_X = 0$。
  - 電源電壓完全降落在漏感上：$v_{Lc} = v_s = V_s \sin(\omega t)$。
  - 漏感電流自 0 開始上升：

$$

i_{Lc}(t) = \frac{1}{L_c} \int_0^t V_s \sin(\omega \tau) d\tau = \frac{V_s}{\omega L_c} (1 - \cos\omega t)$$
  - 續流二極體電流隨之下降：$i_{D2} = I_L - i_{Lc}$。
  - 當 $t = t_a$ 時，$i_{Lc}(t_a) = I_L$ 且 $i_{D2}(t_a) = 0$，$D_2$ 自然截止，換相完成。此時換相角滿足：

$$

\omega t_a = \arccos\left(1 - \frac{\omega L_c I_L}{V_s}\right)$$

- **正常導通區間 Mode II（$t = t_a \sim \pi / \omega$）**：
  - $D_1$ 保持導通，$D_2$ 截止，漏感電流維持 $i_{Lc} = I_L$。
  - 漏感跨壓為零，輸出電壓跟隨電源電壓：$v_X = v_s$。

- **續流換相區間（$v_s < 0$）**：
  - 當電源電壓轉負時，$D_2$ 導通，電流從電源側轉移回續流二極體，直到 $D_1$ 完全截止。

### 2. 漏感對平均輸出電壓的影響
由於換相期間（$0 \sim t_a$）輸出電壓損失為零，平均輸出電壓隨之降低：

$$

V_X = \frac{1}{T} \int_{t_a}^{\frac{T}{2}} V_s \sin(\omega t) dt = \frac{V_s}{\pi} \left(1 - \frac{\omega L_c I_L}{2 V_s}\right)$$
也可改寫為理想輸出電壓扣除等效電阻壓降的形式：

$$

V_X = \frac{V_s}{\pi} - \frac{\omega L_c}{2 \pi} I_L$$

### 3. 最大極限漏感值（$L_{c,\max}$）
當輸出電壓下降至零（$V_X = 0$）時，換相重疊達到極限：

$$

\frac{V_s}{\pi} \left(1 - \frac{\omega L_{c,\max} I_L}{2 V_s}\right) = 0 \implies L_{c,\max} = \frac{2 V_s}{\omega I_L}$$

## 三、直流等效電路模型

考慮漏感影響後，整流系統對負載端的外特性可等效為：
- **等效開路電壓源**：$\frac{V_s}{\pi}$
- **等效內阻**：$R_{eq} = \frac{\omega L_c}{2 \pi}$（此為換相造成的電壓跌落效應，並非真實熱損耗電阻）
- **負載端**：連接負載電阻 $R$ 與平波大電感。
此等效模型可用於快速估算負載端在不同電流下的電壓降落。
