## 📌 3 分鐘核心摘要
- **RL 負載半波與全波整流**：當負載電感 $L \to \infty$ 時，負載等效為理想直流電流源 $I_L$，輸出平均電壓半波為 $V_X = \frac{V_s}{\pi}$、全波為 $V_X = \frac{2V_s}{\pi}$。
- **換向過程（Commutation）**：考慮電源端漏感 $L_c$ 時，二極體 $D_1$ 與續流二極體 $D_2$ 在區間 $[0, t_a]$ 同時導通，輸出端被箝位至 $v_X = 0$。
- **換向角與電流量推導**：漏感電流上升至負載電流需時 $t_a$，滿足換向角公式 $\omega t_a = \cos^{-1}\left(1 - \frac{\omega L_c I_L}{V_s}\right)$。
- **漏感壓降與等效電路**：換向過程導致輸出平均電壓下降，其效應可等效為理想電壓源 $\frac{V_s}{\pi}$ 串聯等效內阻 $R_{eq} = \frac{\omega L_c}{2\pi}$，且存在極限換向電感 $L_{c,\max} = \frac{2V_s}{\omega I_L}$。

## 📖 結構化重點筆記
### 一、RL 負載之理想整流電路（忽略漏感）

#### 1. 半波整流電路（Half-wave Rectifier with RL-load）
- **電路結構**：交流電源 $v_s(t) = V_s \sin(\omega t)$，串聯主二極體 $D_1$，並聯續流二極體 $D_2$，負載為大電感與電阻串聯（$L \to \infty, R$）。
- **電路特性**：
  - 因為 $L \to \infty$，電感電流漣波極小，負載電流近似為恆定直流電流 $i_L(t) = I_L$。
  - 電感兩端平均電壓 $\langle v_L \rangle = 0$，故負載電阻平均電壓等於整流輸出平均電壓：$\langle v_X \rangle = \langle v_R \rangle = V_X$。
- **導通模式（Modes）**：
  - **Mode I ($0 < \omega t < \pi$)**：$v_s > 0$，$D_1$ 導通、$D_2$ 逆偏截止，$v_X(t) = V_s \sin(\omega t)$。
  - **Mode II ($\pi < \omega t < 2\pi$)**：$v_s < 0$，$D_2$ 導通（續流）、$D_1$ 截止，$v_X(t) = 0$。
- **輸出電壓與電流計算**：
  $$V_X = \frac{1}{T}\int_0^{T/2} V_s \sin(\omega t)\,dt = \frac{V_s}{\pi}$$
  $$I_R = I_L = \frac{V_X}{R} = \frac{V_s}{\pi R}$$

#### 2. 全波整流電路（Full-wave Rectifier with RL-load）
- 負載電壓 $v_X(t) = |V_s \sin(\omega t)|$
- 平均電壓：
  $$V_X = \langle v_X \rangle = \frac{2 V_s}{\pi}$$
- 負載電流：
  $$I_L = \frac{2 V_s}{\pi R}$$

### 二、考慮漏感（換向電感 $L_c$）的半波整流電路

在實際電路中，交流電源側存在漏感 $L_c$（換向電感），導致電流無法瞬間由 $D_2$ 轉移至 $D_1$，產生**換向重疊（Commutation Overlap）**。

#### 1. 換向區間分析 ($0 \le t \le t_a$, Mode I 換向期)
- **狀態**：$D_1$ 與 $D_2$ 同時導通。
- **KCL 關係**：$i_L = i_{D1} + i_{D2} = I_L$
- **輸出電壓**：因為 $D_2$ 導通，$v_X(t) = 0$。
- **KVL 關係**：
  $$v_s(t) = v_{Lc} + v_{D1} + v_X \implies v_{Lc} = v_s = L_c \frac{d i_{Lc}}{dt}$$
- **漏感電流推導**（初始條件 $i_{Lc}(0) = 0$）：
  $$i_{Lc}(t) = \frac{1}{L_c} \int_0^t V_s \sin(\omega t)\,dt = \frac{V_s}{\omega L_c}(1 - \cos(\omega t))$$
- **換向結束條件**：
  - 當 $i_{Lc}(t_a) = I_L$ 時，$i_{D2}(t_a) = I_L - i_{Lc}(t_a) = 0$，$D_2$ 自然關斷，換向結束。
  - 換向角 $\omega t_a$ 滿足：
    $$\frac{V_s}{\omega L_c}(1 - \cos(\omega t_a)) = I_L \implies \omega t_a = \cos^{-1}\left(1 - \frac{\omega L_c I_L}{V_s}\right)$$

#### 2. 正常導通區間 ($t_a < t \le \frac{T}{2}$, Mode II)
- $D_1$ 導通、$D_2$ 關斷。
- 漏感電流維持常數 $i_{Lc} = I_L$，故 $v_{Lc} = 0$。
- 輸出電壓恢復為電源電壓：$v_X(t) = v_s(t) = V_s \sin(\omega t)$。

#### 3. 續流區間 ($\frac{T}{2} < t \le T$)
- $v_s < 0$，$D_2$ 導通續流，$v_X = 0$。

---

### 三、換向電感對輸出電壓與電路的影響

#### 1. 平均輸出電壓計算
$$V_X = \langle v_X \rangle = \frac{1}{2\pi} \int_{\omega t_a}^{\pi} V_s \sin(\omega t)\,d(\omega t) = \frac{V_s}{2\pi}\big(1 + \cos(\omega t_a)\big)$$
代入 $\cos(\omega t_a) = 1 - \frac{\omega L_c I_L}{V_s}$：
$$V_X = \frac{V_s}{2\pi} \left(2 - \frac{\omega L_c I_L}{V_s}\right) = \frac{V_s}{\pi} - \frac{\omega L_c}{2\pi} I_L = \frac{V_s}{\pi}\left(1 - \frac{\omega L_c I_L}{2V_s}\right)$$

#### 2. 直流側戴維寧等效電路
- 漏感在輸出端產生的效應為一個**等效壓降電阻**（非實際消耗功率的熱電阻）：
  - 開路輸出電壓：$V_{oc} = \frac{V_s}{\pi}$
  - 等效輸出內阻：$R_{eq} = \frac{\omega L_c}{2\pi}$
  - 負載電流：$I_L = \frac{V_X}{R} = \frac{\frac{V_s}{\pi}}{R + \frac{\omega L_c}{2\pi}}$

#### 3. 最大極限換向電感 ($L_{c,\max}$)
當換向時間延伸至整個半週期結束（即 $\omega t_a = \pi$）時，輸出平均電壓降為零（$V_X = 0$）：
$$1 - \frac{\omega L_{c,\max} I_L}{2V_s} = 0 \implies L_{c,\max} = \frac{2V_s}{\omega I_L}$$
