## 📌 3 分鐘核心摘要
- **RL 負載對整流電路的影響**：當濾波電感 $L \to \infty$ 時，負載側可等效為理想定電流源 $I_L$；半波整流平均輸出電壓為 $V_X = \frac{V_s}{\pi}$，全波整流平均輸出電壓為 $V_X = \frac{2V_s}{\pi}$。
- **換相現象（Commutation）**：引入交流側漏感 $L_c$ 後，二極體無法瞬間切換，會出現 $D_1$ 與 $D_2$ 同時導通的重疊區間（$0 \sim t_a$），此時輸出端被 $D_2$ 箝位至 $v_X = 0$。
- **換相重疊角與壓降**：換相時間由 $i_{Lc}(t_a) = I_L$ 決定，得 $\omega t_a = \cos^{-1}\left(1 - \frac{\omega L_c I_L}{V_s}\right)$；漏感導致輸出平均電壓隨負載電流增加而線性下降，呈現等效內部換相電阻特徵。

## 📖 結構化重點筆記
# 電力電子筆記：單相整流電路與換相重疊分析

---

## 一、理想半波整流電路（含大電感負載 $L \to \infty$）

### 1. 電路結構與基本假設
- **電源**：交流輸入 $v_s(t) = V_s \sin\omega t$
- **結構**：主二極體 $D_1$、續流二極體（Freewheeling Diode）$D_2$、負載電感 $L$ 與負載電阻 $R$
- **大電感假設**：當 $L \to \infty$ 時，電感電流漣波接近零，可將負載等效為**理想直流電流源** $I_L$

### 2. 電感伏秒平衡與平均電壓
根據電感的伏秒平衡原理：
$$\langle v_L \rangle = 0$$
$$\langle v_X \rangle = \langle v_L \rangle + \langle v_R \rangle = \langle v_R \rangle = V_X$$
負載平均電流為：
$$I_L = I_R = \frac{V_R}{R} = \frac{V_X}{R}$$

### 3. 操作模態與波形
- **Mode I ($0 \le \omega t < \pi$)**：$v_s > 0$，$D_1$ 導通、$D_2$ 截止，輸出端電壓 $v_X(t) = v_s(t) = V_s \sin\omega t$。
- **Mode II ($\pi \le \omega t < 2\pi$)**：$v_s < 0$，$D_1$ 截止、$D_2$ 導通續流，輸出端電壓 $v_X(t) = 0$。

輸出平均電壓推導：
$$V_X = \frac{1}{T} \int_{0}^{T/2} V_s \sin\omega t \, dt = \frac{V_s}{\pi}$$
$$I_R = \frac{V_s}{\pi R}$$

---

## 二、全波整流電路（Full-wave Rectifier with RL Load）

- **電路型式**：四顆二極體組成的全波橋式整流器，$L \to \infty$。
- **模態分析**：
  - **Mode I ($v_s > 0$)**：正半周導通，$v_X = V_s \sin\omega t$
  - **Mode II ($v_s < 0$)**：負半周換相導通，$v_X = -v_s = |V_s \sin\omega t|$
- **平均電壓**：
$$V_X = \langle v_X \rangle = \frac{1}{T} \int_{0}^{T} |V_s \sin\omega t| \, dt = \frac{2V_s}{\pi}$$

---

## 三、考慮源端漏感 $L_c$ 的半波整流電路（換相過程）

當交流電源側存在漏感（Leakage Inductance）$L_c$ 時，電流無法瞬間跳變，二極體由導通轉截止時會產生重疊換相區間。

### 1. 模態一：換相重疊區間 ($0 \le t < t_a$)
- **狀態**：$D_1$ 與 $D_2$ 同時 ON（短路箝位）。
- **輸出電壓**：因 $D_2$ 導通，$v_X(t) = 0$。
- **初始條件**：$i_{Lc}(0) = 0$、$i_{D1}(0) = 0$、$i_{D2}(0) = I_L$。
- **KCL 關係**：$i_L = i_{D1} + i_{D2} = I_L$（常數）。
- **KVL 推導**：
  $$v_s = v_{Lc} + v_{D1} + v_X \implies v_{Lc} = v_s = V_s \sin\omega t$$
  $$v_{Lc} = L_c \frac{di_{Lc}}{dt}$$
  $$i_{Lc}(t) = \frac{1}{L_c} \int_0^t V_s \sin\omega\tau \, d\tau = \frac{V_s}{\omega L_c} (1 - \cos\omega t)$$
- **換相終點 ($t = t_a$)**：
  當 $i_{D1}(t_a) = i_{Lc}(t_a) = I_L$ 時，$i_{D2}(t_a) = 0$，$D_2$ 自然關斷（OFF），換相結束。
  $$\frac{V_s}{\omega L_c}(1 - \cos\omega t_a) = I_L \implies \omega t_a = \cos^{-1}\left(1 - \frac{\omega L_c I_L}{V_s}\right)$$

### 2. 模態二：正常導通區間 ($t_a \le t < \frac{T}{2}$)
- **狀態**：$D_1$ ON、$D_2$ OFF。
- **特性**：$i_{Lc} = i_{D1} = I_L$（保持恆定），$v_{Lc} = L_c \frac{di_{Lc}}{dt} = 0$。
- **輸出電壓**：$v_X(t) = v_s(t) = V_s \sin\omega t$。

### 3. 模態三：負半周續流 ($t \ge \frac{T}{2}$)
- **狀態**：$v_s < 0$，$D_2$ ON，$D_1$ 準備截止並進行反向退磁/電流釋放過程。

---

## 四、漏感對整流電壓的外特性影響與等效電路

### 1. 平均輸出電壓受損推導
由於在換相區間 $0 \le t < t_a$ 內原本應有的輸出電壓被箝位至 0，輸出電壓平均值降低：
$$V_X = \frac{1}{T} \int_{t_a}^{T/2} V_s \sin\omega t \, dt = \frac{V_s}{\pi} \left( 1 - \frac{\omega L_c I_L}{2V_s} \right)$$

### 2. 外特性與極限電感
- **外特性下降**：負載電流 $I_L$ 越大或漏感 $L_c$ 越大，電壓降越大。
- **極限狀態 ($V_X = 0$)**：
  令 $1 - \frac{\omega L_c I_L}{2V_s} = 0$，得極限電感：
  $$L_{c,\max} = \frac{2V_s}{\omega I_L}$$

### 3. 直流等效電路模型
整流器受換相影響後的等效直流輸出模型可表示為：
- **開路直流電壓源**：$V_{dc0} = \frac{V_s}{\pi}$
- **等效換相內阻（Commutation Resistance）**：串聯等效阻抗 $R_c = \frac{\omega L_c}{2\pi}$
- **負載端**：串聯直流電阻 $R$
